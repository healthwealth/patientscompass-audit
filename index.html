17 Blog Images Returning 403 Forbidden Easy

Pre-signed CloudFront URLs have expired — causing console errors and broken images

All blog post thumbnail images on d36hbw14aib5lz.cloudfront.net are returning HTTP 403 Forbidden. The ?Expires=…&Signature=… query parameters indicate these are time-limited signed URLs that have now expired.

Recommended fix: For public blog images, remove the signed URL requirement. Make the S3/CloudFront objects publicly accessible and remove the ?Expires&Signature parameters from the image URLs. This also eliminates the cache TTL issue since permanent public URLs can receive long-lived Cache-Control headers.

// ❌ Expired signed URL (403)
https://d36hbw14aib5lz.cloudfront.net/…/sonya_por….jfif?Expires=178…&Signature=…

// ✅ Public permanent URL (no expiry)
https://d36hbw14aib5lz.cloudfront.net/…/sonya_por….jfif
